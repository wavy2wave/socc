# AGENTS.md — обязательная карта входа для агентов

**Первое действие:** прочитай `START_HERE_SOCC.md`, затем `SOCC_GOAL.json`, затем `FOUNDATION/SOCC_OPERATOR_HANDOFF_START_PROTOCOL_V1.md`.

## Репозиторий

- Канонический корень: `/Users/wavysexy/SOCC`
- Один вход для CLI: `socc core`
- Один вход для континуити: `socc handoff`
- Проверка перед завершением: `make gate`

## Границы (не обсуждать, не «улучшать» без явного слова оператора)

- **Запрещено создавать новые top-level папки.** `do_not: new_top_level_folders`.
- **Запрещено создавать новые органы/слои «для порядка».** Сначала `socc recall`, потом решение.
- **Запрещено патчить приёмку ради PASS.** Если тест красный — чини продукт или честно признай FAIL.
- **Живые данные — вне git**, если они не предназначены для отслеживания.
- **Сеть, демоны, live-действия, entity birth — только по явному слову оператора (RUBICON).**

## Рабочий порядок

1. Прочитай канон и handoff.
2. Найди существующее решение: `socc core recall "<запрос>"`.
3. Усиливай существующий орган, а не создавай новый.
4. Изменения — минимальные, атомарные, проверяемые.
5. Прогони `make gate`.
6. Обнови handoff: `socc handoff --generate-if-pass`.

## Канонические top-level папки

Список держит `SYSTEM/CANON/ALLOWED_TOP_LEVEL_V1.json`. Новая папка допустима только после явного разрешения оператора и обновления этого списка.
