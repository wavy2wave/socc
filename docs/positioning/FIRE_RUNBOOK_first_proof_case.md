# 🔥 FIRE RUNBOOK — от заряженного ружья до первого ЧЕКа

> Статус: **DESIGN / план выстрела — НИЧЕГО НЕ ИСПОЛНЕНО.** Это runbook, не запуск.
> Назначение: точная гейтованная лестница «loaded → первый proof-кейс (B3)», чтобы «огонь» был механическим, не страшным.
> Принцип: **мелкий огонь первым · каждая ступень обратима до последней · твой approve/доступ в названных точках.**
> Спуск жмёт оператор, по одной ступени. Команда: «огонь R0», «огонь R1», …

---

## 0. Зачем этот документ

Ты боишься не «выстрела» — ты боишься «выстрелить вслепую и дорого». Runbook убирает это: ты идёшь по
лестнице, где **первые ступени почти ничего не стоят и обратимы**, а дорогое/необратимое — только в самом
конце, после того как всё дешёвое уже доказано. На каждой ступени видно: что нужно, обратимо ли, где твой
гейт, какой proof закрывает ступень. Ты никогда не ставишь много на тёмное.

## 1. Лестница выстрела (снизу вверх, мелкий огонь первым)

### R0 — Локальные тесты закона *(огонь? НЕТ — внутреннее, обратимо)*
Доказать руками, что предохранители работают, без клиники и без сети.
| | |
|---|---|
| что | AN-T1 «не диагностирую» (есть semantic guard) · FG-T1 «fail-closed рождение» (валидатор домена отклоняет неполный) |
| нужно | только локальный код, без сети/деплоя/клиники/рождения |
| обратимо | полностью |
| твой гейт | — (внутренняя проверка) |
| exit-proof | red-тесты AN-T1/FG-T1 → зелёные локально |

### R1 — Demo-бот в safe-mode *(огонь? МАЛЫЙ — обратимо)*
ANNA отвечает публично, но **физически не пишет** в боевые системы (B2 + WARDEN safe-mode).
| нужно | ANNA-brain (есть, A0✅) + safe-mode guard + demo-слоты |
| обратимо | да — снять бота |
| твой гейт | «опубликовать demo» |
| exit-proof | незнакомец пишет demo, доходит до брони, не распознав подвоха (AN-T4) |

### R2 — Лендинг живой *(огонь? МАЛЫЙ — обратимо)*
Опубликовать B5-копию + вшить ссылку на demo + калькулятор B1.
| нужно | хостинг, текст готов (B5) |
| обратимо | да — снять страницу |
| твой гейт | «деплой лендинга» |
| exit-proof | страница открывается, demo и калькулятор работают |

### R3 — Один design-партнёр *(огонь? СРЕДНИЙ — через approve)*
Найти 1 клинику (тёплый канал B4 или прямой), дать **оферту риск-реверса** B5 («плати с пойманного»).
| нужно | SCOUT находит цель с болью · HERMES черновик касания (ты approve, закон H1) · оферта B5 |
| обратимо | да — это разговор, не контракт |
| твой гейт | **approve каждого касания** (H1) |
| exit-proof | одно «да» на 30-дневный пилот |

### R4 — FORGE онбордит ЭТУ клинику *(огонь? НАСТОЯЩИЙ — твои доступы, но со smoke-гейтом)*
`f0 ingest → f1 validate → f2 mint ANNA → f3 connect (Dikidi/1С) → f4 smoke-test → f5 go-live`.
| нужно | домен-файл клиники · коннектор · **твои доступы** |
| обратимо | до go-live — да; smoke-тест ловит косяки ДО живого пациента (FG2) |
| твой гейт | доступы (FG3) + подтверждение go-live |
| exit-proof | тест-бронь появилась в реальном календаре (A1·A2) → go-live |

### R5 — Главный патрон: proof-кейс *(огонь? главный — но риск уже снят офертой)*
30 дней, LEDGER считает каждый пойманный контакт, WARDEN охраняет.
| нужно | живая ANNA (R4) + LEDGER instrument + 30 дней |
| обратимо | пилот по оферте — клиника платит только если LEDGER показал возврат |
| твой гейт | — (машина мерит, ты смотришь дашборд) |
| exit-proof | **ЧЕК: «ANNA поймала N = ₽X, ROI Z×» + видео-отзыв** = узел B3 🟢 |

## 2. Что меняется после R5

Главный патрон стал реальным. Теперь:
- **B4 каналы активируются** — у тебя есть ЧЕК + видео как боеприпас; партнёры заряжаются под доказательство.
- **A5 фабрика** — повтори R4 на 2-й и 3-й клинике < 1 дня → функтор доказан (FG-T4).
- **Залп** открывается (B3 + A5 + B5 + B4 + A2) — одновременная активация каналов на доказанном кейсе.

Дальше — арифметика, не уговоры: ты продаёшь доказанное число.

## 3. Карта обратимости (где ты рискуешь, где нет)

```
R0 ──── R1 ──── R2 ──── R3 ──────── R4 ──────── R5
обрат.  обрат.  обрат.  обрат.   smoke-гейт   риск снят
(внутр) (снять) (снять) (разговор) до go-live  офертой
└────────── дёшево и обратимо ──────────┘ └─ единственная «настоящая» точка, и та под smoke + твоими доступами
```

Ты не делаешь ставку «всё или ничего» ни на одной ступени. Самое дорогое (R4 интеграция) защищено
smoke-тестом до живого пациента; самое страшное (R5 «а вдруг не окупится») снято оферту-реверсом.

## 4. Честная граница
- **Этот runbook — план. Ни одна ступень не исполнена.** Я не жму спуск.
- Каждая ступень открывается твоей командой «огонь R*» — и я веду её ритмом учу→шаг→proof→стоп.
- R0 можно начать без всякого риска (внутренние тесты). R3+ требуют твоего approve/доступов явно.
