# СОВЕТ ДИРЕКТОРОВ ОРГАНОВ — YM_SOVET_V1

> Канон-дизайн «Совета» (Task #8, первый срез 04.09). Движок: `ymarket_sovet_v1.py`,
> приёмка: `tests/run_sovet.py`, шов: шаг 0.5 автопилота `_sovet()`, read-лица: консоль/мозг/ДОМ.

## ЗАЧЕМ (запрос оператора 04.09)
«Нужно что-то вроде живого общения, которое имеет смысл для системы… совет директоров органов:
Управляющий-мозг собирает органы, спрашивает, раздаёт задания, вваливает пропиздоны ленивым.
Так я буду знать, что система жива и трудится в том духе, как мне надо». Оператор прямо спросил:
если для системы это лишнее — не надо. Честный вердикт линз: **совет не лишний, если он ЛИЦЕВАЯ
СТОРОНА уже существующего УТРЕННЕГО ПЛАНА ДНЯ** (plannerka), а не второй источник решений и не театр.

## ТЕЗИС (анти-театр, согласовано 4 линзами)
- **Решения совета = решения ПЛАНА ДНЯ** (`kinds carry|new|escalation|watch`, owner из реестра).
  Совет НЕ авторит новые задания сам, у него НЕТ новых write-ног. Протокол ссылается на `decision_id`
  плана. Одна правда — конфликта двух источников решений нет.
- **Голоса органов — детерминированные данные из их сторов** (0 LLM, 0₽): орган говорит только
  своими данными, каждая фраза несёт источник. Орган без стора/не провязан — в совете ОТСУТСТВУЕТ
  (вакансия не говорит и не получает заданий).
- **Пропиздон — детерминированный miss-движок ДО председателя**, не мнение LLM: вчерашний carry
  открыт сегодня без единого закрытого пункта при существовавшем сухом 0₽ пути. ЯВНЫЕ НЕ-миссы:
  live/RUBICON-блокер (PRICER), QUALITY_UNKNOWN, всё за словом оператора (маппинг). Сегодня реально
  ленивых ~0 → совет честно говорит «пропиздонов нет — упёрлись в слово оператора».
- **Председатель = УПРАВЛЯЮЩИЙ-МОЗГ.** В автопилоте (каденция по тикам launchd 08:07/14:17/20:47,
  НЕ меняем) совет ВСЕГДА сухой: детерминированный свод голосов, 0₽, 0 LLM. Реальный LLM-председатель
  (deepseek-v4-flash через agentrouter) — только за env `YM_SOVET_CHAIR` + слово оператора, в
  интерактивных путях (standalone `--chair` / мозг /совет). Тики 14:17/20:47 лишь рендерят
  существующий протокол даты (идемпотентность по файлу).
- **Анти-враль валидатором**: числа в тексте председателя ⊆ чисел входных голосов (механическая
  токенизация/сверка); голос/факт без ссылки-источника отбрасывается; сбой/пустота LLM →
  детерминированный фолбэк-свод.

## КАДЕНЦИЯ И ШОВ
- УТРО-совет = шаг 0.5 автопилота, сразу после `_plannerka()` (планёрка прежде совета прежде работ).
  Автопилот `run()` БЕЗ commit-параметра (приёмка A2): запись протокола — локальный стор, константа
  `_SOVET_COMMIT = True` ВЕРХНИМ регистром (зеркало `_PLAN_COMMIT`). Кабинет/сеть/₽ — нет.
- Протокол = durable `sovet/ymarket_sovet_<дата>.json` (env `YM_SOVET_DIR` перекрывает).
- Пустой совет (нет голосов/миссов/просьб, т.е. система реально ничего не накопила) → файл даты НЕ
  пишется; heartbeat-строка в логе автопилота; рендер по отсутствию файла честно «совет не собирался».

## СХЕМА ПРОТОКОЛА (`ymarket.sovet.v1`)
```
{schema, date, store, generated_at, mode: dry|chair,
 chair: {mode: svod|llm, by, text, validated: bool, note?},
 voices: [{organ, facts:[{text, source}], nuzhno_slovo: [{what, why, source}]}],
 misses: [{organ, what, since, evidence, task_id}],
 waiting_operator: [{what, why, source}],
 plan: {date, decisions, carry, new, escalation, watch},
 sources: {registry_open, vitrine_live, dossiers, journal}}
```

## ЗАКОНЫ (герметика + анти-вралье, покрыты приёмкой run_sovet)
- VL1 числа председателя ⊆ чисел входных голосов; иначе — детерминированный свод (validated=false).
- VL2 факт/голос без ссылки-источника отбрасывается.
- VL3 пропиздон ТОЛЬКО из miss-движка; прогресс (пункт закрыт) / live / слово оператора — НЕ мисс.
- VL4 dry ничего не пишет; commit → tmp+replace в `sovet/<дата>.json`.
- VL5 пустой совет файл даты НЕ создаёт; рендер по отсутствию — честно «не собирался».
- VL6 once-per-date: файл даты уже есть → повторный resolve не перезаписывает.
- VL7 совет сам НЕ порождает задания (в исходнике нет вызова T.new_task/save реестра/Маркет-записи).

## ГОЛОСА (первый срез — реальные читатели, зеркало plannerka)
ЦИКЛ-1 ← леджер `goods_library` (доказанно живых, СВЕРКА PASS); КАТЕГОРИЙЩИК ← досье (готово/ждут/
маппинг на слове); ДИСПЕТЧЕР ← журнал суточного (горящие заказы, честный 0); РЕЕСТР ← открытые
задания по владельцам. Остальные органы (ФОТО/ОФИС/SELF/СКАУТ/ГОЛОВА) — следующие срезы по мере
ввода их read-читателей; пока их стор не читается — орган в совете отсутствует (не выдумываем).
