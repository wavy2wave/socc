> `ymarket_sovet_spory_v1.py`, приёмка: `tests/run_spory.py` (+ шов в автопилоте A16/A17),
> шов: шаг 0.5b автопилота `_spory()` СРАЗУ после совета, read-лица: консоль/мозг/ДОМ.

## ЗАЧЕМ (запрос оператора 04.09)
Слой 1 (`ymarket_sovet_v1`) сухо фиксирует протокол: кто доложил, кому пропиздон, что упёрлось в слово.
Оператор хочет видеть, что органы реально ГОВОРЯТ ПОЗИЦИЮ над фактами и СПОРЯТ, когда данные тянут
врозь. Слой 2 — прение дня: органы произносят позиции своими сторами (детерминированно, 0 LLM),
а детектор W1–W5 ловит моменты, где позиции/данные реально в конфликте, и предлагает оператору слово.

## ТЕЗИС (анти-театр)
- **Слой 2 — НЕ театр и НЕ второй источник решений.** Позиции выводятся ДЕТЕРМИНИРОВАННО из тех же
  сторов, что совет (каждая фраза с источником, VL2). Совет по-прежнему НЕ сеет заданий (VL7/VL10) —
  каждый спор предлагает ОПЕРАТОРУ слово/решение, ничего не записывая наружу.
- **Позиция НЕ обещает спор, которого детектор не дал.** W1-кандидат считается тем же предикатом,
  что детектор спора (анти-театр: «органы спорить готовы» ≠ «спор есть»).
- **Спор не выдумывается:** орган говорит ТОЛЬКО своим стором; стор не читается → орган молчит
  (вакансия не говорит). Детектор сработал → в grounding лежит текст+источник.
- **LLM-озвучка — опциональный шов под env-гейтом**, НЕ факт: числа озвучки ⊆ чисел фактов (экран
  VL1), принятый голос маркируется «прение — мнение, НЕ факт» (VL9). Озвучка не смешивается с
  grounding-фактами и никогда не выдаётся за решение.
- **Над оперативным УТРЕННИМ ПЛАНОМ** (М3): споры читают план дня тем же путём, что совет
  (PK.load_plan даты; файла нет → build_plan из тех же входов). «Ждёт слова N» СВЕРЯЕТСЯ с текущими
  досье (_reconcile_waiting, 04.09 находка живого доклада): esc-map-{slug}, чьё досье за день уже
  подтверждено органом (need_mapping=false + id дан), из ждущих убирается — числа спора = текущая
  правда, а не утренний след. Ничего не добавляет и НЕ-esc-map эскалации не трогает.

## КАДЕНЦИЯ И ШОВ
- ПРЕНИЕ = шаг 0.5b автопилота, СРАЗУ после `_sovet()` (планёрка → совет → споры → работы). Автопилот
  `run()` БЕЗ commit-параметра (приёмка A2): запись прения — локальный стор, константа
  `_SPORY_COMMIT = True` ВЕРХНИМ регистром (зеркало `_PLAN_COMMIT`/`_SOVET_COMMIT`; A2-гейт сканирует
  исходник на строчный `commit=True`). Кабинет/сеть/₽ — нет.
- **Споры в автопилоте ВСЕГДА сухие и без LLM**: гейт из env `YM_SOVET_SPORY` (нет env → `off`),
  `word=False` → детерминированный слой, 0₽, 0 LLM. Живая озвучка — только в интерактивных путях
  (standalone `--live`/мозг /споры) при env `live` И слове оператора.
- Прение = durable `spory/ymarket_spory_<дата>.json` (env `YM_SPORY_DIR` перекрывает → герметичные
  тесты не трогают канон). Слой 1 (`sovet/`) и его модуль НЕ трогаем — VL8.
- Пустое прение (нет позиций И нет споров — органам нечего противопоставить) → файл даты НЕ пишется
  (VL5); heartbeat-строка в логе автопилота; рендер по отсутствию честно «прений не было».

## СХЕМА ДОКУМЕНТА (`ymarket.sovet.spory.v1`)
```
{schema, date, store, generated_at, mode: off|dry|live, gate, voice_note?,
 positions: [{organ, stance, facts:[{text, source}], proposal?,
             pr_llm?{text, llm:true}|screened?{fired, stripped}}],
 disputes:  [{id, kind: W1..W5, between:[organ, organ],
              summary, grounding:[{text, source}], proposal, note?, pr_llm?}],
 sources:   {registry_open, vitrine_live, dossiers, journal, plan_file}}
```

## ПРЕНИЯ W1–W5 (реальные предикаты, не театр)
- **W1** КАТЕГОРИЙЩИК ⇄ ЦИКЛ-1: готовое досье-партия (ready>0), которой НЕТ в витрине by_category,
  НО план сторожит её как цель дня watch-ready-{slug} — «партия готова, а витрина её не видит».
- **W2** carry/stall владельца: вчерашний carry переносится на завтра без единого закрытого пункта
  (мисс-движок слоя 1), если существовал сухой 0₽ путь.
- **W3** PRICER: открытые задачи живой переценки при пустой витрине / guard не-dict — слово оператора
  (RUBICON), с VL3-оговоркой (НЕ обвинение в лени).
- **W4** УПРАВЛЯЮЩИЙ: «ждёт слова оператора» больше одного (после _reconcile_waiting сверки с
  досье) — «несколько слов повисли, приоритет не назначаю сам».
- **W5** досье `need_mapping=true` против открытого реестра (путь в работу есть, а маппинг не
  подтверждён) — маппинг решает ОРГАН-КАТЕГОРИЙЩИК/человек, споры не сеют.

## ЗАКОНЫ (герметика + анти-вралье, покрыты приёмкой run_spory)
- VL1 числа LLM-озвучки ⊆ чисел фактов (экран); вне → голос отклонён (pr_llm:null + stripped).
- VL2 факт/голос без ссылки-источника отбрасывается (наследуется из SV._clean_voices).
- VL3 владелец на слове оператора (OPERATOR/PRICER) — НЕ мисс; W3 несёт VL3-оговорку, не обвинение.
- VL4 dry ничего не пишет; commit → tmp+replace в `spory/<дата>.json` (свой файл, слой 1 не трогаем).
- VL5 позиции пусты И споры пусты → файл даты НЕ создаётся; рендер по отсутствию — «прений не было».
- VL6 once-per-date: файл даты уже есть → повторный resolve не перезаписывает.
- VL7 споры НЕ порождают заданий: нет T.new_task / T.save / mark_step / seed_from_plan (статич. скан).
- VL8 слой 2 = отдельный файл/стор (spory/), модуль слоя 1 не патчит и не редактирует (файл-заморозка).
- VL9 LLM-озвучка: env `YM_SOVET_SPORY` ∈ {off,dry,live} (off по умолч.) + слово оператора для live;
      числа озвучки ⊆ универсума фактов, принятый голос помечается «прение» (llm:true) и НЕ смешивается
      с grounding-фактами.
- VL10 споры предлагают оператору слово/решение, ничего не пишут наружу и не сеют (зеркало VL7).
