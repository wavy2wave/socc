# YM_CONSOLE_V1 · КОНСОЛЬ-ЯМ · read-кабинет SOCC-ЯМ (ШТАБ-дайв + ДЕЛО)

> Оператор: «Могу провалить в любой орган-сотрудника, увидеть его работу за всё время/за
> сегодня, статы, сколько и какие артефакты. Полный CLI нужен SOCC-ЯМ, где все органы, все
> сотрудники, все циклы.» — КОНСОЛЬ-ЯМ это «смотреть работу органа», НЕ влиять на неё.
> Рядом: `ymarket_console_v1.py`, `ymarket_brain_v1.py` (навигатор), `YM_BRAIN_V1.md` (мозг).

**Pure-read орган**: НИЧЕГО не пишет на диск и сеть не зовёт. Собирает текст из лежащих
сторов (табель/смены/тики через офис, журнал суточного цикла через KPI, матрицу, библиотеку,
торговые точки, реестр ЗАДАНИЙ, хвост автопилота) и рендерит карточки. Функции чистые,
с инъекцией строк (`tabel_rows/journal_rows/charters/ev/doc/tasks=None`) — герметичные тесты
не трогают MEMORY_WAVE.

## Один вход: `CYCLE` / `socc home` — SOCC · ДОМ (хаб органов)

`CYCLE` (симлинк `~/.npm-global/bin/CYCLE` — каталог в интерактивном PATH `.zshrc`; исходник
`scripts/mint/arbiter/CYCLE`) — **фирменный алиас единого хаба SOCC · ДОМ**, движок
`socc_cli.home` (канон интерфейса, см. `SYSTEM/INTERFACE/cli/SOCC_HOME_CLI_V1.md`). Один движок,
два тождественных входа:

- `CYCLE` / `socc home` — дашборд всех органов (КЕРНЕЛЬ · ЯМ-ЦИКЛ · OZON · SUBSTRATE · ANNA)
  с честными зондами-сигнатурами.
- `CYCLE YM` / `socc ym` — весь ЯМ-ЦИКЛ одним экраном: ШТАБ · магазины ЦИКЛ-ДНЯ · ДЕЛО · ЗАДАНИЯ.
- `socc ym <под>` — дело · планёрка · задания · штаб · день · kpi · артефакты · авто · мозг.

Read-фасад над готовыми рендерами `ymarket_console_v1` (ШТАБ/ДЕЛО/ЗАДАНИЯ) +
`ymarket_cycle_day_v1` (магазины планёрки): 0₽, ничего не пишет (проверено: ни одного
write-токена, HH6), цвет на tty / plain в пайпе (CC8=HH2). Справочник под-команд — в docstring
`CYCLE` (`CYCLE --help`). Приёмка хаба: `scripts/socc/socc_home_acceptance_v1.py` → HH1–HH8 8/8.

## One-shot CLI (по полной-команде-конвенции)

```
cd /Users/wavysexy/SOCC/scripts/mint/arbiter
python3 ymarket_console_v1.py --штаб                → 13 ролей одним листом (занятость·совесть·сегодня)
python3 ymarket_console_v1.py --роль ТОВАРОВЕД       → карточка роли (key или русское имя)
python3 ymarket_console_v1.py --табель [--роль X] [--все]  → табель (сегодня | всё время)
python3 ymarket_console_v1.py --день                 → последний снимок журнала суточного цикла
python3 ymarket_console_v1.py --kpi                  → свёртки DAY / WEEK / MONTH
python3 ymarket_console_v1.py --артефакты            → матрица · библиотека · торговые точки
python3 ymarket_console_v1.py --задания              → реестр ЗАДАНИЙ (открытые по важности, владелец)
python3 ymarket_console_v1.py --авто                 → хвост ymarket_autopilot.log
python3 ymarket_console_v1.py --дело                 → всё ДЕЛО одним листом (вкл. ЗАДАНИЯ)
```

Карточка роли (`--роль`): имя+эмодзи · кластер · модуль · проводка · «кто она» (docstring
модуля роли) · занятость (ВАКАНСИЯ/ЧИСЛИТСЯ/СТАЖЁР/В ШТАТЕ) · совесть x/5 · сегодня (ок/skip/
fail) · за всё время (дни·статусы·с какого дня) · последняя работа. Честные пустые: «сегодня
не звалась в цикл» / «табели нет — суточный цикл ещё не провели» (без выдумки, закон L6).

## Источники-сторы (read)

- **Штат**: `ymarket_office_v1.ROLES` — 13 ролей (статично), `load_charters()`/`gather_evidence()`
  → занятость/совесть по реальному следу (память смен, tick-ledger, журнал).
- **Табель**: `MEMORY_WAVE/reports/mint/arbiter/ymarket_office_tabel.jsonl` (schema v1). Мост:
  офис знает `MANAGER`, табель пишет `MANAGER_TICK` — консоль сводит.
- **ДЕЛО**: `ymarket_day_journal.jsonl` (KPI через `kpi.render_all` D/W/M), матрица
  (`matrix.snapshot`, лесенка статусов), библиотека артикулов (`library.stats`), торговые точки
  (`points.load`), реестр ЗАДАНИЙ (`ymarket_tasks_v1` через `tasks_text`/`tasks_reg`, см.
  `YM_TASKS_V1.md`), хвост `ymarket_autopilot.log`.
- Пути перекрываются env (`YM_AUTOPILOT_LOG`, `YM_TASKS_PATH` и пр.) — как у остальных
  read-органов. `--задания` различает «реестра ещё нет» / «реестр битый» / «открыто N» честно
  (CD1-честность на чужом стору) — на пустом каноне просто скажет «реестра ещё нет».

## Законы (CC1–CC9)

| # | закон | как исполняется |
|---|---|---|
| CC1 | **роль_карточка** | карточка роли: имя/кластер/модуль/проводка/занятость/совесть + строки табели «сегодня» и «за всё время» из инъекции. |
| CC2 | **пустая_табель** | нет строк роли сегодня → «не звалась в цикл»; журнал пуст → «табели нет» — без выдуманных цифр. |
| CC3 | **alias_имя** | русское имя/регистр/пробелы → ключ роли (`диспетчер`→DISPATCHER); незнакомое → честный None. |
| CC4 | **день_карточка** | последний снимок дня: дата/burning/top_move/kpis; журнал пуст → честная пустота. |
| CC5 | **кпи_свертка** | DAY/WEEK/MONTH рендер из инъекции журнала; пустой журнал → «журнал пуст». |
| CC6 | **артефакты_сводка** | матрица/библиотека/точки — counts из фикстур; пустые фикстуры → «артикулов нет»/«точек нет». |
| CC7 | **консоль_не_пишет** | исходник без write-путей: нет шелла (`subprocess`/`os.system`), сети (`requests`/`urllib`), открытия на запись, удаления файлов. |
| CC7 | **консоль_не_пишет** | исходник без write-путей: нет шелла (`subprocess`/`os.system`), сети (`requests`/`urllib`), открытия на запись, удаления файлов. |
| CC8 | **цвета_plain** | на не-tty (StringIO/пайп) в тексте нет ANSI — канон `socc_cli.style` out-aware. |
| CC9 | **задания_блок** | read-блок ЗАДАНИЯ: реестр-инъекция → открытые по важности с владельцем/магазином/id; закрытые скрыты; «реестра ещё нет» честно; CC7-источник не пишет. |
