# YM_BRAIN_V1 · SOCC-ЯМ · УПРАВЛЯЮЩИЙ-МОЗГ над MINT (V3: чат + меню-навигатор)

> SOCC-мозг: «я пишу Привет → он отвечает как мой SOCC мозг; даю задание в терминале →
> он инициирует запуск нужных органов/цикла; это управляющий, имеет мозг, доступы все.
> Больше интерактивности, выбора, сразу команды вижу, как в Клауде. С этапа создания
> ЦИКЛА-1 системе пофиг какой API/кабинет — она подрывается; ЦИКЛ-1 ищет маму ЦИКЛ-ЯМ».
> Рядом: `YM_CYCLE1_ENGINE_V1.md` (движок), `ymarket_cycle1_v1.py`, `ymarket_brain_v1.py`.

**ИДЕНТИЧНОСТЬ V3:** SOCC-ЯМ — **мета-цикл (мозг + интерфейс) НАД органом MINT**. Сегодня на
MINT живёт ЯМ (ЦИКЛ-1 «Идея→Товар→Витрина» = ОДИН цикл для одного магазина); завтра приедет
Озон — новым циклом. Дизайн/цвета — SOCC-канон (`socc_cli.style`), тексты — ИЛЯХОВ, форма —
ЛЕБЕДЕВ: «как чат, но можно провалиться в меню».

## 1. Мандат

Мозг отвечает по-русски как со-пилот оператора (коротко, конкретно, с цифрами), зная живое
состояние органа: реестр циклов, пульсы, самоосознание, законы. Он **инициирует** нужные органы:
на вопрос/задание отвечает строкой `[ДЕЙСТВИЕ] <имя> <аргументы>` — строго из каталога ACTIONS.
Сухие/читающие действия выполняются сразу и честно показывают вердикт; живые записи — только
после явного «да» оператора.

## 2. Законы (BR1–BR18)

| # | закон | как исполняется |
|---|---|---|
| BR1 | **мозг сам не пишет** | write-действия (`cycle_live`, `new_cycle`) в `run_action` требуют `confirmed=True`; без него — `НУЖНО СЛОВО`, движок не зовётся. Сухо/чтение (`cycle_dry`, `plannerka`, `self`, `registry`) — авто. RUBICON (L6) держится физически. |
| BR2 | **строгий allowlist** | `plan_action` принимает только имена из `ACTIONS` (плюс семантические алиасы: `мама`/`циклы`→`registry`, `пульс-1`→`cycle_dry`, …). Всё прочее — отказ; в модуле нет `subprocess`/`os.system` — никакого произвольного шелла. |
| BR3 | **секреты не утекают** | в контекст мозга попадают только булевы «ключ задан: да/нет» (`AGENTROUTER_API_KEY`, `YANDEX_MARKET_API_KEY`, ТГ). Значения ключей — никогда. |
| BR4 | **честный оффлайн** | без `AGENTROUTER_API_KEY` мозг говорит «недоступен: нет ключа», не выдумывает; локальные команды (`/мама`, `/само`, `/пульс`) живут. |
| BR5 | **тишина по умолчанию** | сухой ход ЦИКЛА-1 — пульс-строки + вердикт, без россыпи payload; `--verbose` движка открывает полный поток; FAIL показывает хвост ошибки. |
| BR6 | **мама-наследование** | новый магазин объявляет `"mother": "<slug>"` и наследует кабинет (`business_id/campaign_id/warehouse_id`) от глубочайшей мамы; товарные поля (донор/builder/markup/остаток) — свои у каждого цикла. Система агностична к API. |
| BR7 | **REPL сухо и живьё** | стаб мозга `[ДЕЙСТВИЕ] cycle_dry` → сухой ход сразу; `[ДЕЙСТВИЕ] cycle_live` → ждёт «да», «нет» → RUBICON, движок не тронут. |
| BR8 | **пустой ответ LLM** | relay вернул только thinking → 2-й заход с пинком; повторная пустота → `{ok:False, empty:True}` → ответ телом SOCC, НЕ тупик. |
| BR9 | **тело SOCC в контексте** | `build_context()` несёт донор-модель (магазин-поставщик ≠ `donor_category`), доктрину, RUBICON, глоссарий пульс-1/мама/хеш. |
| BR10 | **пульс-1 запускаем** | `[ДЕЙСТВИЕ] пульс-1 <store>` = прогон цикла (alias→`cycle_dry`); оффлайн сам инициирует сухой прогон. |
| BR11 | **оффлайн-фолбэк** | `_ask` пуст → REPL отвечает из тела SOCC (не «мозг недоступен»), не пусто, сухо-авто живо. |
| BR12 | **меню-навигатор** | «меню» → корень = список циклов MINT (★ = живой) → внутрь цикла (пульс/сухо/живьё/карточка) → 0 назад → 0 в чат. |
| BR13 | **короткий ответ** | показ-версия режет длинный ответ (голова + ≤9 строк), но `[ДЕЙСТВИЕ]`-строку из хвоста сохраняет; полный текст — в истории. |
| BR14 | **спиннер молчит вне tty** | `_with_spinner` на StringIO/пайпе не пишет ANSI-мусор, значение функции возвращает; кадры «думаю…» — только на живом терминале. |
| BR15 | **лог не на диске в тесте** | REPL с заданным stdin (тесты) сессия-лог на диск не пишет — runtime/ чист; лог живёт на реальном терминале. |
| BR16 | **корень один список** | корень = 1..N циклы · N+1 создать · N+2 ШТАБ · N+3 ДЕЛО · 0 в чат (N динамически); цифры N+2/N+3 ведут внутрь веток. |
| BR17 | **штаб-дайв** | меню N+2 → лист 13 ролей (занятость·совесть·сегодня) → цифра → карточка роли (консоль), 0 назад к штабу → к циклам. |
| BR18 | **дело-чтение** | меню N+3 → KPI/ДЕНЬ/ТАБЕЛЬ/АРТЕФАКТЫ/АВТОПИЛОТ/ДЕЛО — read-рендер консоли на реальных сторах, write не зовётся. |

### ШТАБ/ДЕЛО (уровни 10/11/20, КОНСОЛЬ-ЯМ)

На корне два пункта меню проводят в read-кабинет (0₽, ничего не пишет): **N+2 · ШТАБ** —
13 ролей органа одним листом (имя 🚚 · кластер · занятость · совесть x/5 · сегодня ок/skip/fail),
цифра 1–13 проваливает в **карточку роли** (кто она, модуль, проводка, занятость, совесть,
сегодня/за всё время/последняя работа — честные пустые «не звалась в цикл»/«табели нет»).
**N+3 · ДЕЛО** — KPI (D/W/M) · ДЕНЬ (снимок журнала) · ТАБЕЛЬ (кто сегодня) · АРТЕФАКТЫ
(матрица·библиотека·точки) · АВТОПИЛОТ (хвост лога) · ДЕЛО одним листом. Всё — чтение сторов
через `ymarket_console_v1` (см. `YM_CONSOLE_V1.md`), законы CC1–CC8. Команды в чате: `/штаб`,
`/роль <имя|key>`, `/kpi`, `/день`, `/табель [--роль X] [--все]`, `/артефакты`, `/авто`, `/дело`.

## 3. Каталог действий (ACTIONS)

| имя | роль | авто? | что делает |
|---|---|---|---|
| `cycle_dry [--store X]` | dry | ✅ | сухой ход ЦИКЛА-1 (0₽; СВЕРКА реальным чтением). Тихий: пульс+вердикт. |
| `cycle_live [--store X]` | write | ⛔ «да» | ЖИВОЙ ход (`--commit`) — пишет в кабинет. Только по слову оператора. |
| `plannerka [--store X]` | read | ✅ | пульс/планёрка магазина (последний прогон). |
| `self` | read | ✅ | самоосознание управляющего (карточки/индекс/следующий шаг). |
| `registry` | read | ✅ | реестр циклов: кто какому мама-циклу наследует кабинет. |
| `new_cycle <slug> <builder> <donor_category> <markup> <stock> [--mother M]` | write | ⛔ «да» | новый магазин в `stores.json` (файл, НЕ сеть). Без mother и кабинета — авто-мать `atlas-express-film`. |

Формат запуска из мозга: `[ДЕЙСТВИЕ] cycle_dry --store box-msk`. Сухо/read → выполняется сразу
с печатью вердикта; write → REPL спрашивает «Подтверди [да/нет]:», без «да» ничего в сеть/манифест
не пишется.

## 4. Интерфейс V3: чат + меню (SOCC-канон)

```
python3 ymarket_brain_v1.py
управляющий> привет                  → спиннер «думаю…» → ответ SOCC-мозга (коротко, ≤6–8 строк)
управляющий> меню                    → навигатор SOCC-ЯМ, корень = ОДИН СПИСОК MINT
                                       1..N — живой цикл (пульс сегодня + вердикты), дальше строка деталей
                                       (кабинет · ×markup · ост N · пульс {дата} {PASSx DRYy} · арт N)
                                       N+1 · создать цикл (мастер) · N+2 · ШТАБ · N+3 · ДЕЛО · 0 · в чат
                                       приглашение «циклы> »
цифра (на корне, ≤N)                 → внутрь выбранного цикла (level 1: 1 ПУЛЬС · 2 ЦИКЛ сухо ·
                                       3 ЦИКЛ живьё · 4 КАРТОЧКА цикла · 0 назад к циклам),
                                       приглашение «цикл:{slug}> »; любой текст = чат, «меню» = сюда
N+2 (ШТАБ, level 10)                 → 13 ролей одним листом; цифра 1–13 → карточка роли (level 11,
                                       приглашение «роль:{key}> »), 0 → назад к штабу → к циклам
N+3 (ДЕЛО, level 20)                 → 1 KPI · 2 ДЕНЬ · 3 ТАБЕЛЬ · 4 АРТЕФАКТЫ · 5 АВТОПИЛОТ ·
                                       6 ДЕЛО одним листом · 0 назад; read-рендер, приглашение «дело> »
запусти цикл плёнки сухо             → [ДЕЙСТВИЕ] cycle_dry → авто, компактная карточка узлов
сделай цикл живьём                   → вопрос «да/нет»; без слова — отмена (RUBICON)
/штаб · /роль диспетчер · /дело      → КОНСОЛЬ-ЯМ: штаб/карточка роли/дело (read 0₽, см. §4)
/kpi · /день · /табель [--роль X] [--все] · /артефакты · /авто
/мама · /реестр                      → кто от какой мамы наследует кабинет
/само · /пульс [store]               → самоосознание / планёрка
/цикл сухо [store] · /цикл живьё     → прямой ход движка (сухо 0₽; живьё спросит слово)
/новый-цикл box-msk box korobki 6 50 → в манифест (спросит слово)
/лог                                 → хвост сегодняшней сессии (пишется на живом терминале)
/выход · Ctrl-D
```

Правила интерфейса: показ-версия ответа режется (голова + `[ДЕЙСТВИЕ]`-строка, полный текст в истории);
цвета — только на живом tty (в тестах/пайпах — plain, канон-код не мусорит); после каждого ответа
без действия — строка «→ дальше: «меню»…». ЦИКЛ-1 сухой ход в каждом ответе САМ не гоняется —
только по прямой просьбе оператора или на «что дальше/как дела», если сегодня ещё не прогоняли.

One-shot (CI/автопилот/дым): `--say "текст"` (контекст+ответ, действия анонсируются, НЕ выполняются),
`--organs`, `--self`, `--registry`, `--pulse [store]`.

## 5. Тихий движок (для ЦИКЛА-1)

«Многа букав» сухого хода (полные payload из `ymarket_write_v1._dry`) больше не льётся в терминал:
`run_cycle` исполняет каждый узел под захватом stdout, наружу идут только пульс-строки и итоговый
вердикт. Честность FAIL не теряется — при ошибке показывается хвост захваченного вывода
(~14 строк), полный поток открывает `--verbose`.

## 6. Мама-реестр (кабинет-agnostic вход)

Манифест `runtime/cycle1/stores.json` — канонический вход. Дочерний магазин:

```json
{ "box-msk": { "slug": "box-msk", "mother": "atlas-express-film",
  "donor_category": "korobki", "builder": "box", "markup": 6.0, "stock_count": 50 } }
```

`resolve_profile` (чистая функция) до-заполняет кабинет от глубочайшей мамы по цепочке `mother`
(защита от циклов — честный FAIL «цепь замкнута»), поля ребёнка приоритетнее. Товарные поля
никогда не наследуются. Хеш цикла `sha1(slug×дата×версия)[:10]` позволяет N магазинов параллельно,
каждому свой леджер/пульс.

## 7. Приёмка

`python3 tests/run_yandex_brain.py` → **BR1–BR18 PASS · 18/18** (0₽, без сети: движок/мозг/HTTP мокаются).
КОНСОЛЬ-ЯМ: `python3 tests/run_yandex_console.py` → **CC1–CC8 PASS · 8/8** (read-орган, инъекция строк).
Регрессия: `python3 tests/run_yandex_autopilot.py` зелёный (7/7, RUBICON-законы автопилота не задеты).
Дым: `python3 ymarket_brain_v1.py --say "привет"` → ответ SOCC-мозга (нужен `AGENTROUTER_API_KEY`
в `mint/.env`, уже заряжен; без ключа мозг честно говорит «недоступен», локальные команды живут).
Живой REPL: «меню» → навигатор, «привет» → спиннер «думаю…» → короткий ответ, «запусти цикл плёнки
сухо» → авто сухой ход ТИХО 0₽, `/лог` → хвост сессии.
