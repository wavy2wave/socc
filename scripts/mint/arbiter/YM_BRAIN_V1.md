# YM_BRAIN_V1 · УПРАВЛЯЮЩИЙ-МОЗГ органа ARBITER (ЦИКЛ-1 + тишина + мама-реестр)

> SOCC-мозг: «я пишу Привет → он отвечает как мой SOCC мозг; даю задание в терминале →
> он инициирует запуск нужных органов/цикла; это управляющий, имеет мозг, доступы все.
> Больше интерактивности, выбора, сразу команды вижу, как в Клауде. С этапа создания
> ЦИКЛА-1 системе пофиг какой API/кабинет — она подрывается; ЦИКЛ-1 ищет маму ЦИКЛ-ЯМ».
> Рядом: `YM_CYCLE1_ENGINE_V1.md` (движок), `ymarket_cycle1_v1.py`, `ymarket_brain_v1.py`.

## 1. Мандат

Мозг отвечает по-русски как со-пилот оператора (коротко, конкретно, с цифрами), зная живое
состояние органа: реестр циклов, пульсы, самоосознание, законы. Он **инициирует** нужные органы:
на вопрос/задание отвечает строкой `[ДЕЙСТВИЕ] <имя> <аргументы>` — строго из каталога ACTIONS.
Сухие/читающие действия выполняются сразу и честно показывают вердикт; живые записи — только
после явного «да» оператора.

## 2. Законы (BR1–BR6)

| # | закон | как исполняется |
|---|---|---|
| BR1 | **мозг сам не пишет** | write-действия (`cycle_live`, `new_cycle`) в `run_action` требуют `confirmed=True`; без него — `НУЖНО СЛОВО`, движок не зовётся. Сухо/чтение (`cycle_dry`, `plannerka`, `self`, `registry`) — авто. RUBICON (L6) держится физически. |
| BR2 | **строгий allowlist** | `plan_action` принимает только имена из `ACTIONS` (плюс семантические алиасы: `мама`/`циклы`→`registry`, …). Всё прочее — отказ; в модуле нет `subprocess`/`os.system` — никакого произвольного шелла. |
| BR3 | **секреты не утекают** | в контекст мозга попадают только булевы «ключ задан: да/нет» (`AGENTROUTER_API_KEY`, `YANDEX_MARKET_API_KEY`, ТГ). Значения ключей — никогда. |
| BR4 | **честный оффлайн** | без `AGENTROUTER_API_KEY` мозг говорит «недоступен: нет ключа», не выдумывает; локальные команды (`/мама`, `/само`, `/пульс`) живут. |
| BR5 | **тишина по умолчанию** | сухой ход ЦИКЛА-1 — пульс-строки + вердикт, без россыпи payload; `--verbose` движка открывает полный поток. |
| BR6 | **мама-наследование** | новый магазин объявляет `"mother": "<slug>"` и наследует кабинет (`business_id/campaign_id/warehouse_id`) от глубочайшей мамы; товарные поля (донор/builder/markup/остаток) — свои у каждого цикла. Система агностична к API. |

## 3. Каталог действий (ACTIONS)

| имя | роль | авто? | что делает |
|---|---|---|---|
| `cycle_dry [--store X]` | dry | ✅ | сухой ход ЦИКЛА-1 (0₽; СВЕРКА реальным чтением). Тихий: пульс+вердикт. |
| `cycle_live [--store X]` | write | ⛔ «да» | ЖИВОЙ ход (`--commit`) — пишет в кабинет. Только по слову оператора. |
| `plannerka [--store X]` | read | ✅ | пульс/планёрка магазина (последний прогон). |
| `self` | read | ✅ | самоосознание управляющего (карточки/индекс/следующий шаг). |
| `registry` | read | ✅ | реестр циклов: кто какому мама-циклу наследует кабинет. |
| `new_cycle <slug> <builder> <donor_category> <markup> <stock> [--mother M]` | write | ⛔ «да» | новый магазин в `stores.json` (файл, НЕ сеть). Без mother и кабинета — авто-мать `atlas-express-film`. |

Формат запуска из мозга: `[ДЕЙСТВИЕ] cycle_dry --store box-msk`. Сухо/read → выполняется сразу
с печатью вердикта; write → REPL спрашивает «Подтверди [да/нет]:», без «да» ничего в сеть/манифест
не пишется.

## 4. REPL «как в Клауде»

```
python3 ymarket_brain_v1.py
управляющий> привет                        → ответ SOCC-мозга (контекст: реестр+само+законы)
управляющий> запусти цикл плёнки сухо      → [ДЕЙСТВИЕ] cycle_dry → авто, компактный вердикт
управляющий> сделай цикл живьём            → вопрос «да/нет»; без слова — отмена (RUBICON)
управляющий> /мама · /реестр               → кто от какой мамы наследует кабинет
управляющий> /само                         → самоосознание управляющего
управляющий> /пульс [store]                → планёрка магазина
управляющий> /цикл сухо [store]            → прямой сухой ход движка (0₽)
управляющий> /новый-цикл box-msk box korobki 6 50   → в манифест (спросит слово)
управляющий> /выход · Ctrl-D
```

One-shot (CI/автопилот/дым): `--say "текст"` (контекст+ответ, действия анонсируются, НЕ выполняются),
`--organs`, `--self`, `--registry`, `--pulse [store]`.

## 5. Тихий движок (для ЦИКЛА-1)

«Многа букав» сухого хода (полные payload из `ymarket_write_v1._dry`) больше не льётся в терминал:
`run_cycle` исполняет каждый узел под захватом stdout, наружу идут только пульс-строки и итоговый
вердикт. Честность FAIL не теряется — при ошибке показывается хвост захваченного вывода
(~14 строк), полный поток открывает `--verbose`.

## 6. Мама-реестр (кабинет-agnostic вход)

Манифест `runtime/cycle1/stores.json` — канонический вход. Дочерний магазин:

```json
{ "box-msk": { "slug": "box-msk", "mother": "atlas-express-film",
  "donor_category": "korobki", "builder": "box", "markup": 6.0, "stock_count": 50 } }
```

`resolve_profile` (чистая функция) до-заполняет кабинет от глубочайшей мамы по цепочке `mother`
(защита от циклов — честный FAIL «цепь замкнута»), поля ребёнка приоритетнее. Товарные поля
никогда не наследуются. Хеш цикла `sha1(slug×дата×версия)[:10]` позволяет N магазинов параллельно,
каждому свой леджер/пульс.

## 7. Приёмка

`python3 tests/run_yandex_brain.py` → **BR1–BR7 PASS** (0₽, без сети: движок/мозг/HTTP мокаются).
Регрессия: `python3 tests/run_yandex_autopilot.py` зелёный (RUBICON-законы автопилота не задеты).
Дым: `python3 ymarket_brain_v1.py --say "привет"` → ответ SOCC-мозга (нужен `AGENTROUTER_API_KEY`
в `mint/.env`, уже заряжен; без ключа мозг честно говорит «недоступен», локальные команды живут).
