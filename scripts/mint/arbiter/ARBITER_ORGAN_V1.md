# ARBITER — ОРГАН SOCC · карта (один источник правды)

> Единственное место, где перечислены ВСЕ подорганы оси ARBITER, суточный цикл и статусы.
> Это **индекс** — ведёт к реальным файлам, не дублирует их нутро. При добавлении/смене подоргана правим **здесь**.

**Место в SOCC:** кластер **MINT** → вечная ось `ARBITER_LINE_V1` (регистрация: [ARBITER_LINE_V1.json](ARBITER_LINE_V1.json), `schema socc.line.v1`).
Ядро цикла t0..t6 переиспользует `scripts/mint/socc_mint_cycle_v1.py`. Нос СПРОСА — WB; витрины — **Яндекс.Маркет** (боевая) и **Ozon** (зеркало).

> json-декларация вех — **историческая** гейт-лестница (M0..M6). Денежные гейты (**M4 «первый verified ₽»**) НЕ пройдены (реальных ₽ = 0). Эта карта = фактическая глубина стройки, **не** заявка о пройденных гейтах. Не переписывать json ретроспективно.

**Законы (RUBICON):** запись наружу только `not dry AND commit`; автопилот физически без commit-пути; деньги двигает только оператор; **никаких закупок заранее** — выкуп у донора ТОЛЬКО после оплаченного заказа.

> **Модель фулфилмента: Express 148619267** — выбор оператора и ДОКТРИНАЛЬНО ВЕРНЫЙ (не развилка). Доктрина «не закупаем заранее» СОВМЕСТИМА с Express: на оплаченный заказ оператор за ~1 мин оформляет заказ на cargo-avto (деньгами клиента), курьер Яндекса забирает товар ПРЯМО у донора (склад 2390811 = точка cargo) по внутреннему №. Товар не держим, деньгами не рискуем. **DBS НЕ нужен** (вывод «Express→DBS» оператор опроверг 2026-08-12: «ты не понял»).
