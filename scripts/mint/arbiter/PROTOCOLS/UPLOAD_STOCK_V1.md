   Пока вердикт не снят в кабинете — товар на витрину не встанет. Это и есть «недопустимые ошибки».
2. **Карточка размещена в Экспресс-магазине.** Сейчас `BW_3328199` есть только в DBS `148611270`
   (`DISABLED_BY_PARTNER`); в FBS/Express `135962876` и `148619267` — 0 офферов.
   Публикация (STEP 3 ниже) и есть то, что кладёт оффер в магазин с ценой.
3. **Express-склад включён (модель EXPRESS).** Подтверждено: склады `1652222` / `1803385`,
   оба `express=True`. Адрес пункта читаем из кабинета, не хардкодим.
4. **contentRating приемлем.** `BW_3328199` = 52 (считается Яндексом асинхронно, ~раз в сутки).
   Низкий рейтинг → КОНТРОЛЁР держит в зоне, ТОВАРОВЕД доливает карточку.

## ШАГИ (сухо → один commit). Якорь = имя функции; строки ≈ (могут дрейфовать).

### STEP 0 — КАНДИДАТ (КАТЕГОРИЙЩИК) · 0₽
Донорский XLSX (`cargo-avto`) → ранжированный шорт-лист под Экспресс.
`ymarket_role_categorist_v1.read_donor` парсит строки; цена из файла = НАША закупка,
цену продажи предлагаем ×5–10. *(Автоматизацию донор→prod ведёт смежная линия — раннер `--donor`.)*

### STEP 1 — СБОРКА prod (ТОВАРОВЕД) · 0₽
`ymarket_from_xlsx_v1.row_to_prod` → dict товара: specs, габариты (вложенный `weightDimensions`
+ плоские length/width/height), фото-гейт (`photo_source_matches` + `verify_pictures` — свои пиксели).

### STEP 2 — ПУБЛИКАЦИЯ карточки (ТОВАРОВЕД) · сухо/0₽ → commit
`ymarket_write_v1.publish_card` → `create_card` → `card.to_offer(prod)`
(цена = `int(round(price))`, `marketCategoryId` или слаг-фолбэк). Четыре API-шага под капотом:

1. **offer-mappings** — `hands.update_offer_mappings(bid, …)` (заводит связь offerId↔карточка).
2. **offer-cards** — параметры карточки. ENUM emit-ится **valueId + value ВМЕСТЕ**
   (`card.profile_parameter_values`); перед отправкой `validate_against_live`.
   *(шаг пропускается, если `marketCategoryId=None`.)*
3. **campaign-offers** — `place_in_campaign` → `hands.update_campaign_offers(cid, …)`.
   ← **ЭТО кладёт оффер в магазин с ценой** (закрывает предусловие №2).
4. **проверка** — `check_visibility` → `hands.campaign_offers(cid, [oid])` читает `status == PUBLISHED`.

### STEP 3 — ОСТАТОК (СКЛАДОВЩИК) · сухо/0₽ → commit
`ymarket_trade_hands_v1.update_stocks(business_id, [{sku, warehouse_id, count}], dry, commit)`.
Уровень БИЗНЕСА (в пути только `business_id`, **нет** `campaign_id`). `count` честный:
не знаешь — ставь 0 (лучше ноль, чем ложь; `count=0` легально снимает с витрины).
Верхняя обёртка: `ymarket_role_stockman_v1.plan(items, warehouse_id)` → `push(...)`.

### RUBICON — единственный рубильник
Всё выше по умолчанию **сухо** (`dry=True, commit=False`) → ни одного POST.
Боевой write ТОЛЬКО так: `python3 ymarket_day_v1.py --commit` под явным словом оператора.
**Через автопилот пути к commit НЕТ** (зашито физически).

## FAKEPROOF (доказано сухо, 0₽)

**Половина ОСТАТОК** (этот кабинет, 2026-08):
```
trade.update_stocks(184481130, [{sku:"BW_3328199", warehouse_id:1803385, count:30}], dry=True)
→ {"status":"dry","sent":false,"method":"POST",
   "path":"/v3/businesses/184481130/offers/stocks/update",
   "payload":{"skuItems":[{"sku":"BW_3328199","partnerWarehouseId":1803385,"count":30}]}}
```
И `dry=False, commit=False` — POST **всё равно не ушёл** (гейт `if dry or not commit`).
`count=30` — сухая метка-заглушка, не решение об остатке.

**Половина ЗАЛИВКА:** богато заполненная карточка проходит весь write-путь сухо/0₽/без ключа
(доказано на смежной линии, категория коробов 76296786).

## ЦИКЛ ЗАКРЫТ (успех узла)
Карточка `PUBLISHED` в Экспресс-магазине · остаток честный · индекс КОНТРОЛЁРА зелёный · вердикта нет.
Тогда: **маркет** принял (опубликовано), **покупатель** может купить (видно + есть остаток),
**мы** не соврали (остаток честный, цена выше пола). Группа процессов удовлетворила всех троих.

## ИДЕМПОТЕНТНОСТЬ / ПОВТОР
- Карточка уже `HAS_CARD_CAN_UPDATE` → повторная заливка = обновление, не дубль.
- Остаток перезаписывается (не накапливается): последний `update_stocks` = истина.
- Заказ + сшивка (`express_stitch.jsonl`) = `ALREADY_FULFILLED` — не выкупаем дважды (это узел ЗАКАЗЫ, отдельный протокол).
