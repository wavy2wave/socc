# Автопродление подписок — настройка cron

Движок автопродления (`renewals.py`) запускается **периодически** из cron — **не как daemon**.

## Как это работает

1. Cron прогоняет `python3 renewals.py` раз в час.
2. Скрипт просматривает все подписки:
   - **Предупреждает заранее** о предстоящем списании (за 3 дня, настраивается через `WAVE_RENEW_NOTICE_DAYS`).
   - **Списывает деньги** по истёкшим подпискам с привязанной карты.
   - **Продлевает** срок от старого `paid_until` (клиент не теряет дни).
   - **Ставит на паузу** после 3 провалов (карта отклонила списание).
3. Выходит — cron запустит снова через час.

### Идемпотентность

Если cron прогонится дважды по одной просроченной подписке (сбой, ручной запуск) — **списания дважды не будет**. Идемпотентность-ключ стабилен для одного периода:

```python
idem = f"{user_id}:{product_id}:{int(sub['paid_until'])}"
```

ЮKassa вернёт тот же платёж, а не создаст новый.

### Fail-soft

Одна сломанная подписка (exception) не убивает всю пачку — остальные клиенты продлятся нормально.

## Настройка crontab

### 1. Откройте crontab

```bash
crontab -e
```

### 2. Добавьте строку

```cron
# WAVE SHOP — автопродление подписок (раз в час)
# Минута 17 выбрана намеренно: не :00 и не :30, чтобы не создавать пик нагрузки
17 * * * * cd /Users/wavysexy/SOCC/scripts/mint/wave_shop && /usr/bin/python3 renewals.py >> /Users/wavysexy/SOCC/scripts/mint/wave_shop/data/renewals.log 2>&1
```

**Почему минута 17, а не :00?**  
Все, кто пишет «раз в час», ставят `0 *` — и запросы со всей планеты попадают на провайдера одновременно. Смещение на несколько минут снимает пик.

### 3. Проверьте, что cron работает

```bash
# Посмотреть список задач
crontab -l

# Убедиться, что cron-демон запущен (macOS)
sudo launchctl list | grep cron
```

### 4. Следите за логом

```bash
tail -f /Users/wavysexy/SOCC/scripts/mint/wave_shop/data/renewals.log
```

Каждый прогон печатает сводку:
```
[renewals] предупреждений=2 списано=3 (+23700 ₽) провалов=0 на_паузе=0 сбоев=0
```

```bash
cd /Users/wavysexy/SOCC/scripts/mint/wave_shop
python3 renewals.py
```

Покажет сводку и выйдет. Безопасно запускать сколько угодно раз — идемпотентно.

## Что делать, если подписка не продлилась

1. Смотрите `data/renewals.log` — там будет причина (ошибка провайдера, отклонённая карта).
2. Проверьте, что `WAVE_AUTORENEW_ENABLED=true` в `.env`.
3. Проверьте, что у подписки `autorenew: true` и есть `payment_method_id` (привязанная карта).
4. Если карта отклонила списание 3 раза — автопродление встало на паузу, клиенту пришло уведомление. Он должен продлить вручную или обновить карту.

---

## Отключение

Удалите строку из crontab:
```bash
crontab -e
# Удалите строку с renewals.py
```

Подписки перестанут продлеваться автоматически. Оплаченный срок сохранится до конца.
