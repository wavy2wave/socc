# Разведка спроса за 30–60 минут (GO / NO-GO) — прежде чем строить хоть что-то

> Цель: за один вечер узнать ГЛАВНОЕ — **есть ли живой платящий спрос** на твою услугу. Это тот единственный
> факт, что разблокирует MINT/ANNA/Entity Substrate. 0 ₽, 0 кода. Ты не продаёшь — ты СЧИТАЕШЬ спрос.
> (Research-харнесс уточнит связки; но это правило работает для любой из них.)

## Гипотеза, которую проверяем
«Есть люди, которые ПРЯМО СЕЙЧАС ищут и готовы платить за Telegram-бота / ИИ-автоматизацию под ключ.»

## Процедура (засеки 45 минут, живьём, своими глазами)
Иди туда, где спрос УЖЕ платит. Не постить-и-ждать, а СМОТРЕТЬ активные запросы:

1. **YouDo** → раздел «Программирование» / «Чат-боты» / «Виртуальный помощник». Открой ленту заданий.
   Считай свежие (за 1–3 дня) задания «нужен бот / автоответчик / автоматизация / нейросеть».
2. **Profi.ru** → зарегистрируйся исполнителем в «Разработка ботов», «Нейросети/ChatGPT», «Автоматизация».
   Смотри поток новых заказов. Сколько релевантных в день?
3. **Kwork** → поиск «телеграм бот», «чат-бот», «автоматизация»: сколько продавцов, какие цены, у топов —
   сколько ВЫПОЛНЕННЫХ заказов/отзывов (это прямое доказательство, что покупают и по чём).
4. **Avito** → «Услуги» + раздел Заданий: поиск «нужен телеграм бот», «настроить бота», «автоматизация заявок».
5. **Telegram** → поиск чатов «фриланс / ищу подрядчика / нужен бот / автоматизация»; полистай за сегодня.

## Правило решения (жёсткое, без самообмана)
Посчитай **N** = сколько РЕАЛЬНЫХ свежих запросов «нужен бот/автоматизация» ты увидел за 45 минут суммарно,
и **K** = у топ-исполнителей Kwork/Profi сколько выполненных заказов на этой услуге.

- **GO (спрос есть):** N ≥ 3 свежих запроса И K ≥ 10 выполненных у конкурентов.
  → Спрос доказан. Отвечаешь на эти запросы сегодня же (шаблоны ниже) → цель: первая сделка.
- **СЛАБО:** N = 1–2 → спрос тонкий для этого оффера. Смени НИШУ (не «бот вообще», а «бот записи для
  барбершопов/салонов/автосервисов») или снизь цену/добавь демо. Повтори разведку.
- **NO-GO:** N ≈ 0 И конкурентов почти нет → на эту услугу тут не идут. **Не строй ничего.** Меняем связку
  (research даст следующего кандидата).

> Смысл: если конкуренты закрыли 100+ заказов «бот за 1500₽» — связка РАБОЧАЯ, вопрос только твоего входа.
> Если пусто — никакой webhook/оферта/сущность не создадут спрос, которого нет.

## 3 готовых отклика (персональные, с раскрытием, демо до оплаты, чек НПД)
На конкретный запрос отвечай коротко и по делу:

**A. На запрос «нужен телеграм-бот для записи/заявок»:**
> Здравствуйте! Сделаю такого бота под ключ за 1 день: меню, приём заявок (имя+телефон вам в Telegram),
> автоответы на частые вопросы. Покажу рабочий пример ДО оплаты. Работаю как самозанятый, дам чек НПД.
> Цена 1500 ₽ (первым клиентам ниже рынка ради отзыва). Пришлите нишу — покажу демо под неё.

**B. На запрос «настроить GPT / нейросеть под задачу»:**
> Здравствуйте! Возьму вашу задачу под ключ: настрою нейросеть под ваш процесс (ответы клиентам / разбор
> таблиц / генерация текстов) + короткая инструкция. Сделаю сегодня, если задача узкая. Не подойдёт —
> доработаю бесплатно. Самозанятый, чек НПД. Опишите задачу в 2–3 фразах.

**C. На запрос «автоматизировать рутину / таблицы / выгрузки»:**
> Здравствуйте! Автоматизирую вашу рутину: перенос данных, обработка таблиц/писем, простые интеграции.
> Скажите, что делаете вручную каждый день — предложу решение и цену. Демо покажу до оплаты, чек НПД дам.

## Что дальше
- Нашёл первый живой запрос → **пришли мне его текст**. Я: (1) напишу под него точный выигрышный отклик
  живым мозгом, (2) заведу claim в MINT, (3) когда клиент заплатит и ты дашь услугу → `record --commit` →
  **первый реальный ₽**.
- Результат разведки (GO / СЛАБО / NO-GO) тоже пришли — от него зависит, бьём этот оффер или берём
  следующий из research-шортлиста.

**Один ответ «да, сколько стоит?» от реального человека = гипотеза подтверждена. Это дороже 68 зелёных тестов.**
