# M1 CLOSE — от ответа клиента до первого ₽ (где сделки умирают и как не дать)

> Спрос найден (DEMAND_TEST), клиент ответил. Тут 80% новичков теряют деньги. Ниже — механика закрытия:
> точки смерти и точный ответ на каждую. Zero-capital, неубиваемо (ты не фронтишь риск), чек НПД.

## Правило №1: скорость + демо = доверие без отзывов
Ответил в первые минуты + сразу дал ссылку на ЖИВОЙ демо-бот → половина сделки закрыта. Собери 1 демо-бот
заранее (бот-фабрика, `config.sample.json`), это твой главный актив: клиент ВИДИТ результат до оплаты.

## Диалог-воронка (5 шагов, не больше)
1. **Квалификация:** «Какая ниша/задача? Что бот должен делать в первую очередь?»
2. **Демо:** «Вот живой пример: @<твой_демо_бот>. Под вас будет так же, но с вашими текстами.»
3. **Скоуп (зафиксируй письменно!):** «В базовом за 1500 ₽: меню, автоответы на 5 вопросов, кнопка заявки
   → вам в Telegram. Срок 1 день.» ← что НЕ входит — назови сразу (оплата в боте, CRM, GPT = доп. опции).
4. **Цена + срок + оплата:** «1500 ₽, 1 день. Оплата через Безопасную сделку площадки / или 50% сейчас,
   50% после сдачи. Чек НПД дам.»
5. **Закрытие:** «Делаем? Пришлите 5 вопросов-ответов и название — запускаю сегодня.»

## Точки смерти → точный ответ
- **«Дорого».** → «Первым клиентам 1500 ради отзыва, дальше дороже. Демо бесплатно — платите, только когда
  увидите готового бота под вас.» (демо + постоплата убивают «дорого».)
- **«А не кинешь / не пропадёшь?»** → «Работаю через Безопасную сделку площадки: деньги замораживаются, я
  получаю после вашей приёмки. Самозанятый, дам чек НПД — вот как это выглядит.»
- **Твой риск «а меня не кинут?»** → бери **эскроу площадки** (Kwork/YouDo/Avito «Безопасная сделка») ИЛИ
  **50% предоплату** на счёт самозанятого (СБП) + чек. **Полную работу без коммита не начинаешь.**
- **Scope creep («добавьте ещё…»)** → «Это в базовом. <Фича> — доп. опция +X ₽, оформим отдельно.»
- **«Пришлите ТЗ / договор»** → короткая оферта из бота (см. HANDOFF, юр.щит) + переписка = сделка по ГК РФ.

## Механика оплаты 0-капитал (неубиваемость)
Приоритет источников (по безопасности для тебя):
1. **Эскроу площадки** — лучшее: деньги держит гарант, ты не рискуешь, спор решает площадка.
2. **50% предоплата + 50% по сдаче** (СБП на счёт самозанятого) — вне площадки.
3. Полная предоплата — только по доверию/рекомендации.
**Комплаенс-гейт (жёстко): продукт клиенту НЕ отдаёшь, пока не пришли деньги И не сформирован чек НПД.**
Это одновременно анти-кидок и защита от налоговой (`деньги == чек == ledger`).

```bash
cd ~/SOCC/scripts/mint/botfactory
python3 socc_botfactory_v1.py --new "<Имя клиента>"      # конфиг под нишу

```
Отдаёшь клиенту: ссылку на бота + видео-инструкцию «как менять тексты».

## Чек НПД = точка транзакции
«Мой налог» → Новая продажа → Физлицо → сумма → отправь клиенту QR/ссылку. Это и есть момент, когда деньги
законно стали доходом.

## Запись в орган (первый реальный ₽)
```bash
python3 ~/SOCC/scripts/mint/socc_mint_record_v1.py \
  --service "Telegram-бот автоответчик" --amount 1500 \
  --lead-ref "<id заявки/контакт>" --source moy_nalog_receipt --ref "<receipt_id>" --inn <ИНН> --commit
```
→ `verified ₽` в каноне, само-модель перещёлкнет, появится паттерн-«бог». **Первая точка транзакции закрыта.**

## Чек-лист одной сделки (распечатай в голове)
`[ ] ответил быстро` → `[ ] дал демо` → `[ ] зафиксировал скоуп+цену+срок` → `[ ] взял эскроу/предоплату` →
`[ ] собрал бота` → `[ ] пришли деньги` → `[ ] сформировал чек НПД` → `[ ] отдал продукт` → `[ ] record --commit`.
