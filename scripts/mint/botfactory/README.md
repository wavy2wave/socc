# Bot-Factory — фабрика Telegram-ботов (актив вселенной D2)

Переиспользуемый бот-автоответчик «под ключ». Один код → новый клиент = новый `config.json` (5 минут).
Он же **демо-бот**, который закрывает сделку без отзывов. Продукт услуги P3 (см. `../P3_FIRST_LEAD_RUNBOOK.md`).

## Файлы
| файл | роль |
|---|---|
| `socc_botfactory_v1.py` | рантайм (aiogram, ленивый) + логика (stdlib) + `--check` / `--new` |
| `config.sample.json` | образец конфига (барбершоп) |
| `socc_botfactory_acceptance_v1.py` | фальсифицируемые тесты BF-T1..BF-T5 (без сети/aiogram) |

## Как доставить клиента (повторяемо)
```bash
cd ~/SOCC/scripts/mint/botfactory
python3 socc_botfactory_v1.py --new "Имя клиента"      # 1) создать config.<имя>.json
#   → отредактировать: меню (услуги/цены/адрес/часы), faq, lead.fields, owner_chat_id (chat_id владельца)
python3 socc_botfactory_v1.py --check config.<имя>.json # 2) проверить конфиг + увидеть дерево диалога (без запуска)
pip install aiogram                                     # 3) один раз
BOT_TOKEN=<токен из @BotFather> python3 socc_botfactory_v1.py config.<имя>.json   # 4) запустить бота
python3 socc_botfactory_acceptance_v1.py               # приёмка фабрики (BF-T1..T5)
```
Демо-бот для продаж: заполни `config.sample.json` под вымышленный бизнес, подними на своём токене — показывай в откликах.

## Что делает бот
`/start` → приветствие + меню-кнопки. Кнопка → ответ из конфига; кнопка `__LEAD__` → собирает имя+телефон →
форвардит владельцу (`owner_chat_id`) с отметкой согласия (152-ФЗ). Свободный текст → ответ из `faq` или меню.

## Закон (RL4 / 152-ФЗ)
Бот легальный: без спам-рассылок, токен — клиента, данные клиента бот не трогает (только форвард заявки
владельцу), согласие на обработку ПД — в форме заявки. Деньги клиента через бота не проходят (не мул).
