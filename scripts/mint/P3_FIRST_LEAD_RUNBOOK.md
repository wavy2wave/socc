# P3 — Первый реальный ₽: рунбук добычи лида (ИИ/автоматизация, самозанятый)

> Клин органа MINT, вселенная D2 `service-leadgen-RU`. Исполнитель — ты (самозанятый, ИП есть).
> Цель: один реальный платящий клиент → услуга оказана → чек НПД → **первый verified ₽ в каноне**.
> Сделано воркфлоу `mint-p3-first-lead-ai-automation` (5 каналов). Синтез ниже.

## Продукт (4 из 5 каналов сошлись на нём — это сигнал)
**«Telegram-бот-автоответчик под ключ за 1 день».** Дёшево купить, легко доставить, реальный спрос.
- **Что входит:** приветствие + меню (цены/адрес/часы/услуги/контакты) · автоответы на 5–7 частых вопросов ·
  кнопка «Оставить заявку» → имя+телефон падают владельцу в Telegram мгновенно · хостинг 30 дней + видео-инструкция.
- **Цена первой продажи:** 1500 ₽ (самому первому можно 990 ₽ ради скорости и отзыва).
- **Доставка:** готовый шаблон (aiogram / no-code конструктор), под клиента меняются только тексты и токен → 1.5–3 ч.

## Канал-стратегия (по скорости до первого ₽)
| канал | путь | дней | как берём первый заказ |
|---|---|---|---|
| **YouDo** | отклики на свежие заявки, «Сделка без риска» | ~3 | первым на «нужен бот/автоответчик», фикс 1500₽, «сегодня» |
| **Telegram-чаты + холодный B2B** | мониторить чаты бизнеса/подрядчиков, демо-бот | ~3 | ответ за 2-3 мин + ссылка на живой демо, «оплата после демо» |
| **Avito Услуги** | объявление + охота в «Требуется» | ~4 | 10-15 откликов/день с демо, «первым 3 за отзыв» |
| **Kwork** | продуктизированный кворк (входящий трафик) | ~5 | цена −200₽ к топу, срок «1 день», быстрый ответ в чате |
| **Profi.ru** | платные отклики на ИТ-задачи | ~5 | топ-5 по скорости, план в 3 шага под задачу, фикс 990₽ |

**Рекомендация (синтез):** охота на АКТИВНЫЕ заявки (YouDo + Avito «Требуется» + TG-чаты) — там клиент уже хочет купить, это быстрее входящего. Параллельно повесить пассивный кворк на Kwork. **Ключевой актив — собрать ОДИН демо-бот заранее: он снимает страх и закрывает сделку без отзывов.**

## План 7 дней до первого ₽
- **День 0:** проверить активный статус самозанятого («Мой налог») · собрать 1 демо-бот (живая ссылка).
- **День 1:** Kwork-кворк + Avito-объявление + профили YouDo/Profi (тексты — ниже).
- **Дни 2–5:** ежедневно 10–15 откликов на свежие заявки про ботов + мониторинг TG-чатов; в каждый отклик — ссылка на демо. Первый «да» → собрать бота за день → сдать.
- **Транзакция:** клиент принял работу → оплата (эскроу площадки / СБП) → **чек НПД в «Мой налог»** → первый ₽.
- **Дни 6–7:** добить до 2–3 сделок + реальные отзывы (они разблокируют поток).

## Красные линии (иначе бан/штраф — и это RL4 органа)
Только **реальные** отзывы (никакой накрутки/покупки) · оплата и общение через площадку до разрешённого
момента (не уводить в обход эскроу) · без спам-рассылок, без парсинга/обхода API площадок и Telegram ToS ·
согласие на обработку перс. данных в форме заявки (152-ФЗ) · **чек НПД на каждый платёж** · не обещать
«гарантию продаж».

## Подключение к органу MINT (когда лид станет реальным)
Как только есть реальная заявка — одна команда пишет `claim` в **канон**, после услуги и чека — `verify`:

```python
import sys; sys.path.insert(0, "scripts/mint")
from socc_mint_service_cycle_v1 import run_service_connection, D2_SERVICE

lead = {
  "service": "Telegram-бот-автоответчик",
  "ticket_value": 1500,                 # чек клиента (он же доход самозанятого, исполнитель — ты)
  "executor": "<твоё имя/самозанятый>",
  "lead_ref": "<id заявки YouDo/Avito или 'direct-<контакт>'>",  # RUBICON t2: реальная заявка
  "source": "youdo",                    # avito|profi|youdo|kwork|direct
}
res = run_service_connection(
  D2_SERVICE, lead, mode="real",
  fulfilled=True,                       # RUBICON t3: бот РЕАЛЬНО сдан и принят
  payout={"source": "moy_nalog_receipt",# RUBICON t4: реальный чек НПД
          "ref": "<receipt_id из Мой налог>", "amount": 1500, "inn": "<твой ИНН>"})
print(res["status"], res["proof"]["truth_boundary"])
```
`verified=true` встанет в канон ТОЛЬКО при реальном чеке/поступлении. Тогда:
```bash
python3 scripts/mint/socc_mint_self_v1.py --emit   # само-модель: «реальных 0» → первый ₽, «бог» найден
MINT_DASH_PORT=8792 python3 scripts/mint/socc_mint_dashboard_v1.py  # дашборд: первый verified ₽
```
