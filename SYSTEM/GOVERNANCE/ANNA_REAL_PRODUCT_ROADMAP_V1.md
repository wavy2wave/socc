## Северная звезда (обновлённая цель)
**ANNA — живой, человеко-неотличимый и НЕУБИВАЕМЫЙ администратор клиники, который реально
возвращает клинике потерянные обращения и выручку, рождён и управляем сувереном SOCC по закону
(proof, гейты, no-fake-pass), и масштабируется как продукт-сущность до 1000+ клиник.**

Заменяет `SOCC_GOAL.json` («build ANNA Dental MVP first-contact runtime» — это была веха MVP, не продукт).

**Мета-цель — ПОРЯДОК:** одна основная линия на одну цель; никакого дрейфа, никаких дублей.
Работа над продуктом дисциплинируется так же, как знание дисциплинируется spine.

**Не обсуждается:**
- Никогда не ломается у платящей клиники (неубиваемость **доказана**, не заявлена).
- Никогда не выдаёт себя ботом (stealth-канон D3).
- Никогда не ставит диагноз / не назначает лечение (граница администратора).
- Цифра выгоды — только из реальных данных клиники / LEDGER, не из воздуха.

Ближайший фронтир: **L0 (порядок) + L1/L2 (надёжность + реальная запись)**. Прыжки через слой запрещены.

## Закон карты
Каждый слой проходит ту же законную под-цепочку, что и ANNA MVP (18 шагов):
`direction → review → accept → план → review → научный/Hermes/Codex гейты → review → accept →
bounded surface → review → accept → bounded session → validate → review → accept → seal → ship`.
Между слоями — честный гейт. No-fake-pass: статус слоя вычисляется из реального состояния, не из желаний.
