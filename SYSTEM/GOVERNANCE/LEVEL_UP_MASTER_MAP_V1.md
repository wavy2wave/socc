## 1. Честное зеркало (сначала самое важное)

**(а) Рекурсивный дубль — пойман на себе.** И многолетний план (`ANNA_REAL_PRODUCT_ROADMAP_V1`),
и инструмент дисциплины линий (`scripts/socc/socc_lines_v1.py`) **уже лежали на диске** — а эта
задача почти их продублировала. Это и есть боль L0, доказанная на живом примере: линии строят
одно и то же, не зная, что оно уже есть. **Вывод:** не ковать третий план — свести в один и
достроить ровно ОДНУ недостающую деталь.

**(б) Стале-факт исправлен — мозг ЖИВ.** В self-model висит блокер «автономный цикл стоит на
мёртвом LLM-мозге (401/402)». Проверка показала: `api.freemodel.dev` отвечает 200, ключ валиден,
`anna_runtime_v1.py --demo` прошёл end-to-end на gpt-5.4-mini 2026-06-30. **Блокер устарел.**
Не трать сессию на «восстановление мозга» — перепроверь одним `--demo` и сними флаг.

**(в) Настоящий блокер — НАРУЖУ, не внутрь.** Всё зелёное (B0, CONDUCTOR, FG-T1, движки
SCOUT/HERMES) — внутрь, на сэмплах. Всё красное (R1–R5, B3, AN-T3) — наружу, к живой клинике.
**Ни один владелец клиники ещё не коснулся ANNA.** Доска готовности зелена внутрь и красна
наружу — она мерит не ту ось. Продукт начинается там, где её касается чужой человек.

## 3. Единая лестница (три оси сведены в одну)

**Продуктовая ось (ЧТО умеет)** — из `ANNA_REAL_PRODUCT_ROADMAP_V1`:

```
L0 дисциплина линий → L1 неубиваемый мозг → L2 реальная запись → L3 первая клиника(₽)
→ L4 кабинет владельца → L5 мультиканал → L6 живое обучение → L7 флот→1000 → L8 фабрика вертикалей
```

**Огневая ось (КАК доходим до денег)** — из `FIRE_RUNBOOK`:

```
R0 локальные тесты закона → R1 demo safe-mode → R2 лендинг живой → R3 один партнёр(approve)
→ R4 FORGE онбордит(smoke-гейт) → R5 proof-кейс 30 дней = ЧЕК
```

**Денежные вехи (когда уровень «взят» в ДЕНЬГАХ):**
- **M1 — Первый ЧЕК:** ₽X из LEDGER одной клиники + видео-отзыв (= B3🟢 = L3 = R5).
- **M2 — Функтор доказан:** FG-T3 полный на ≥2 клиниках, онбординг №3 < 1 дня, 0 правок кода (= L7/A5).
- **M3 — Сетевой эффект:** метрика СТАРЫХ клиник растёт как f(N) клиник в сети (= L8/моат).

**Карта сшивки (одна строка = один уровень):**

| Продукт | Огонь | Деньги | Falsifiable-гейт | Горизонт | Огонь оператора? |

## 4. Гейты — фальсифицируемые, по уровням (no-fake-pass)

- **COCKPIT-T1 (L0):** `socc_lines_v1.py scan` перечисляет каждую живую `claude`-линию (pid+uuid+тема),
  две линии с одним `--resume`-uuid считает ОДНОЙ, объявляет дубль только при совпадении ≥2 каналов,
  делает 0 записей/убийств. FAIL: фантом-дубль, или тронут хоть один транскрипт.
- **L1 мозг:** убей провайдера → авто-failover отвечает законно; AN-T1 «не диагностирую» режет
  медицинские промпты (semantic guard). FAIL: тишина при смерти провайдера, либо утёк диагноз.
- **L2 запись:** smoke-бронь от ANNA появляется в реальном календаре и идемпотентна на повтор.
  FAIL: не появилась / двойная бронь / запись ДО smoke-гейта.
- **A0/R1 safe-mode (исправлено — без «не распознал бота»):** незнакомец доходит до шага брони
  **И** не сработала ни одна боевая запись (WARDEN safe-mode доказывает 0 живых вызовов) **И** 0
  диагнозов (AN-T1). _«Не заметил, что бот» убрано — это чувство, не факт._
- **L3/R5 деньги (M1):** «ANNA поймала N = ₽X, ROI Z×», где N счётно в LEDGER, клиника подтверждает
  на видео, платит только если LEDGER показал возврат. FAIL: N заявлен без событий, либо нет клиники.
- **L7/FG-T3 функтор (M2):** один mint-вызов рождает законную dental-ANNA И барбершоп из домен-файлов,
  0 правок кода. FAIL: правка кода = это вторая стройка, не функтор.
- **L8 сеть (M3):** метрика старых клиник растёт как функция N. FAIL: не зависит от N = это сумма, не сеть.

|---|---|---|

| Диагноз/лечение от бота | **323-ФЗ** (мед.деятельность лицензируется) | Есть: жёсткий закон «не диагностирую» + semantic guard (100% vs denylist 60%) + AN-T1. Держать: любой дрейф к симптомам → «записываю к врачу» |

| СНГ ≠ один режим | РФ/РК локализуют, **РБ — нет** (Закон 99-З, но реестр операторов) | Домен-файл FORGE несёт параметр `legal_regime` (RU/KZ/BY/…), меняющий mint-блокеры. Это и есть TFS-1 «домен-как-параметр» в законе |

## 6. Где оператор ОБЯЗАН печатать сам (Λ₀ — машина истину не присваивает)

4. **R3 первый партнёр** — оферту риск-реверса и разговор авторизуешь лично.
5. **R4 go-live** — твои доступы Dikidi/1С + подтверждение go-live ПОСЛЕ smoke-теста.

7. **«Огонь»** — стройка/исполнение начинается только по твоей команде, одна обратимая ступень за раз.
