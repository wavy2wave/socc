# SOCC Operator · Метрики

## Правило

Метрика без proof — не метрика.

## North Star

> **Cost per verified operation** — стоимость одного проверенного действия в деле.

Формула:

```text
CPO = (инфраструктура + compute + человеко-время + риски) / verified_effective_actions
```

Цель: CPO ↓ со временем.

## Операционные метрики

| метрика | как измеряем |
|---|---|
| время аудита | время от запуска до отчёта |
| число найденных проблем | issues с evidence |
| доля закрытых задач | done / total |
| скрытые объекты | витрина/сток |
| ошибки карточек | errors[] |
| расхождения сверки | ledger vs truth |
| часы оператора | замер до/после |

## Экономические метрики

| метрика | смысл |
|---|---|
| сэкономленные часы | оператор освобождён |
| предотвращённые потери | ошибки/остатки/цены |
| прирост оборота | продажи/записи |
| маржа | цена − cost |
| LTV клиента | продолжительность подписки |

## Trust-метрики

| метрика | смысл |
|---|---|
| доля dry→commit | качество подготовки |
| FAIL без ущерба | система останавливается безопасно |
| proof coverage | доля действий с proof |
| rollback success | восстановление |

## Memory-метрики

| метрика | смысл |
|---|---|
| повторное использование уроков | lessons used |
| снижение времени задачи | task cost N+1 < N |
| доля повторных ошибок | ↓ |
| canonical path reuse | ↑ |

## Honest boundaries

- projection ≠ proof;
- план ≠ результат;
- 200 OK ≠ успех;
- выполнение без эффекта = semantic null.
