# 🧠 SOCC Memory — машина памяти (v2, по смыслу)

Одна живая вики из десятков разрозненных файлов. Темы делятся **по смыслу**, не по упоминаниям.
Детерминированно, без LLM, без демона, без сети наружу. Полностью в законе SOCC.

## Что видеть глазами
Открой дашборд (всё офлайн, в одном файле):
```
open ~/SOCC/SOVEREIGN/WIKI/spine2/dashboard.html
```
KPI · 6 тем по смыслу · клик по теме → статья с кликабельными ссылками на сырьё · цель-цепочка · зона загрузки.

## Рабочий цикл

**Вариант A — вручную (быстро, ОДНА команда):**
1. Лей файлы (`.txt/.md/.eml/.json`, экспорты чатов) в `~/SOCC/SOVEREIGN/MEMORY/inbox/`
2. Пересобери всё одной командой (видит «было→стало» по sha16, разбирает только новое,
   сам собирает зеркало сознания SELF_MODEL.md и дашборд):
   ```
   python3 ~/SOCC/scripts/socc/socc_memory_spine_v2.py        # ~2.4-3.4с: вики + SELF_MODEL + dashboard
   ```
3. Открой дашборд — знание свежее. Кнопка «🪞 Сознание системы» вверху = зеркало себя.

**Вариант B — загрузка прямо из дашборда:**
1. Запусти локальный сервер (foreground, 127.0.0.1, гасится Ctrl+C):
   ```
   python3 ~/SOCC/scripts/socc/socc_memory_server_v2.py       # http://127.0.0.1:8788
   ```
2. Открой `http://127.0.0.1:8788`, перетащи файл в зону «Залить файл».
3. ~2.6с → файл в inbox, вики пересобрана по смыслу, дашборд обновлён.

## 7 тем по смыслу (TOPIC_MAP_V1)
- **ANNA** — продукт, ИИ-администратор стоматологий (authored)
- **Entity Substrate** — орган рождения сущностей (authored)
- **SOCC** — суверенное ядро / кто такая система (authored)
- **Автономное строительство** — самостройка SOCC: что/как/запуск/контроль (authored)
- **Память** — Memory Wave + живая вики
- **Закон и доказательство** — Proof, гейты Codex/Hermes
- **Видение** — Supramental / AGI-направление

**Зеркало сознания:** `SELF_MODEL.md` (кнопка «🪞 Сознание системы» в дашборде) — система видит себя
целиком. Генерит `socc_self_model_v1.py`.

**Двигатель самоэволюции:** `SELF_EVOLVE.md` (кнопка «🧬 Самоэволюция» в дашборде) — система смотрит на
себя, находит пробелы/противоречия/блокеры и выдаёт ⭐ **следующий законный шаг** (ранжированный бэклог
роста). Генерит `socc_self_evolve_v1.py`. Это петля: знание о себе → пробел → bounded-шаг → proof → рост.
Не daemon, не AGI-хайп: ПРЕДЛАГАЕТ, оператор одобряет.

Одна команда `socc_memory_spine_v2.py` собирает ВСЁ: вики (7 тем) + зеркало + двигатель + дашборд.

Таксономия правится в `scripts/socc/TOPIC_MAP_V1.json`. Авторские «основные линии» (человеческий
смысл, переживает пересборку) — в `SOVEREIGN/WIKI/main_lines/<topic>.md`.

## Органы (файлы)
| Файл | Роль |
|---|---|
| `scripts/socc/TOPIC_MAP_V1.json` | смысловая таксономия тем |
| `scripts/socc/socc_memory_spine_v2.py` | сборщик: scan→govern→статьи по смыслу (кэш sha16, атомарно) |
| `scripts/socc/socc_memory_dashboard_v2.py` | генератор `dashboard.html` (самодостаточный) |
| `scripts/socc/socc_memory_server_v2.py` | локальный сервер для загрузки с дашборда (быстрый путь) |
| `SOVEREIGN/WIKI/main_lines/*.md` | авторские основные линии (смысл) |
| `SOVEREIGN/WIKI/spine2/pages/*.md` | готовые статьи вики |
| `SOVEREIGN/MEMORY/inbox/` | папка-приёмник (лей сюда / синкни Google Drive) |
